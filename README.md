# 회의 녹음기

브라우저에서 녹음하고 **사용자가 입력한 OpenAI API 키로 직접 전사·요약·교정**합니다. GitHub Pages에서도 별도 전사 서버 없이 사용할 수 있습니다.

## 사용 방법

1. 앱의 톱니바퀴 **환경설정**을 엽니다.
2. **OpenAI API 키**에 본인의 키를 붙여넣고 **이 탭에서 사용**을 누릅니다.
3. 언어·마이크·전문용어를 선택하고 **마이크 준비**를 누릅니다.
4. 녹음 버튼을 누르면 같은 마이크 입력을 WAV로 저장하며 30초마다 OpenAI로 전사합니다.
5. 녹음 종료 후 남은 구간이 처리되면 요약·교정·보관함 저장을 사용할 수 있습니다.

키 입력 후에는 입력란을 비웁니다. **키 삭제**, 새로고침, 페이지 이동 시 메모리의 키가 제거됩니다. API 키는 localStorage, sessionStorage, IndexedDB, 서버, 저장 파일에 기록하지 않습니다. 보관함에는 녹음·전사·언어·날짜만 저장합니다.

키가 없어도 녹음·저장은 가능합니다. 전사가 멈췄다면 키를 입력한 뒤 **전사 재시도**를 누르세요. 키를 삭제하면 진행 중인 요청을 취소하고 이후 요청은 키를 다시 입력할 때까지 중단됩니다. 이미 OpenAI가 처리한 요청의 비용이 취소되는 것은 아닙니다.

## 데이터와 API 연결

- 브라우저 → `https://api.openai.com/v1/audio/transcriptions` (`gpt-4o-transcribe`)
- 브라우저 → `https://api.openai.com/v1/responses` (`gpt-4o-mini`, `store:false`)
- 키는 OpenAI 요청의 Authorization 헤더에만 포함됩니다. 앱 호스팅 서버로 보내지 않습니다.
- 녹음은 전사할 때, 전사 내용은 요약·교정할 때 OpenAI로 전송됩니다. API 사용료는 입력한 키의 계정에 청구됩니다.
- 브라우저 메모리에 보관하는 동안 페이지 코드나 확장 프로그램은 키에 접근할 수 있습니다. 신뢰하는 기기에서 본인 키로 사용하세요. 공유 서버 비밀키를 HTML에 넣어 배포하지 마세요.
- OpenAI는 서버 측 키 보관을 권장합니다. 이 앱의 직접 호출은 사용자가 본인의 키를 입력하는 개인 사용 흐름입니다. 공식 안내: [API 인증](https://developers.openai.com/api/reference/overview).

## 로컬 실행

Node.js 22 이상에서 추가 패키지 없이 실행할 수 있습니다.

```sh
npm start
```

http://127.0.0.1:3000 을 열고 환경설정에서 키를 입력하세요. **현재 웹 앱에는 `.env`나 서버의 `OPENAI_API_KEY`가 필요하지 않습니다.** HTTPS 정적 호스팅에서도 같은 방식으로 동작합니다.

기존 `server.js`의 `/api/transcribe`·`/api/ai` 경로는 이전 연동 호환용으로 남아 있지만 현재 화면은 호출하지 않습니다. 서버 환경변수는 그 기존 경로를 별도 사용할 때만 필요합니다. 외부에서 Node 서버를 제공하는 경우 기존 `APP_ORIGIN`·`APP_PASSWORD` 설정을 사용하세요.

## 녹음과 파일

- 마이크 준비는 권한과 장치를 미리 초기화하며 아직 녹음·전송하지 않습니다. 미사용 2분 후 자동 해제합니다.
- AudioWorklet의 연속 PCM으로 전체 WAV와 30초 전사 구간을 만듭니다. 종료 시 마지막 잔여 구간도 보냅니다.
- 실제 마이크 음량을 표시하며, 언어·전문용어·이전 전사 문맥을 API에 전달합니다.
- 파일 불러오기 후 **파일 전사**로 24MB 이하 오디오도 처리할 수 있습니다.
- 현재 녹음과 재시도 큐는 메모리에 있습니다. 페이지를 닫기 전에 다운로드하거나 보관함에 저장하세요. 보관함은 현재 브라우저·접속 주소의 IndexedDB에 저장됩니다.
- 메모리 사용을 제한하기 위해 세션당 1시간 녹음 후 종료합니다. 긴 회의는 나눠 저장하세요.
- 화면 잠금·백그라운드·통화·블루투스 변경은 녹음을 중단할 수 있습니다. 모바일 실기기에서 확인하고 화면을 켜 두세요.

## 테스트

```sh
npm run check
npm test
```

자동 테스트는 오디오 구간/헤더, 키 필요 여부·삭제·요청 취소·오류 메시지, 직접 API 요청 형식, 기존 서버 호환성을 확인합니다.

선택적 Chrome 통합 테스트:

```sh
npm install --no-save --package-lock=false playwright@1.62.1
npm run test:browser
npm run test:pages
```

테스트용 키와 API 응답 대역, 가상 마이크를 사용합니다. 실제 키를 전송하거나 비용을 발생시키지 않습니다. Pages 테스트는 하위 경로의 정적 사이트에서 키 입력·삭제·새로고침, 키가 브라우저/보관함에 저장되지 않는지, 키가 앱 서버로 전송되지 않는지, 전사·요약·교정을 확인합니다. `BROWSER_EXECUTABLE`로 브라우저 경로를 지정할 수 있습니다.

실제 유효한 키로 유료 전사·요약 호출 및 인식률 비교, iPhone/Safari 실기기 검증은 별도 필요합니다. 브라우저·네트워크·OpenAI의 CORS 정책에 따라 직접 연결이 차단되면 오류를 표시합니다.

공식 문서: [음성 전사](https://developers.openai.com/api/docs/guides/speech-to-text), [텍스트 생성](https://developers.openai.com/api/docs/guides/text).
