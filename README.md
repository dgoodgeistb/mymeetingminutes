# 회의 녹음기

기존 한국어 웹 앱의 화면·언어 선택·텍스트 저장·녹음 재생·IndexedDB 보관함을 유지하고, 하나의 마이크 입력으로 녹음과 서버 전사를 처리합니다.

## 실행

Node.js 22 이상이 필요합니다. 런타임 외 추가 패키지는 없습니다.

```sh
cp .env.example .env
# .env의 OPENAI_API_KEY를 설정합니다.
npm start
```

브라우저에서 http://127.0.0.1:3000 을 여세요. 키를 입력하지 않아도 녹음·저장은 가능하며 전사는 키 설정 후 재시도할 수 있습니다. ChatGPT 구독과 API 사용료는 별도입니다.

1. 환경설정에서 마이크와 전문용어/참석자 이름을 선택합니다.
2. **마이크 준비**로 권한 요청과 오디오 처리를 미리 준비합니다. 이때 마이크는 켜지지만 녹음 저장·전송은 시작하지 않습니다. 2분간 사용하지 않으면 자동 해제됩니다.
3. 녹음 버튼을 누릅니다. 같은 입력으로 실제 음량을 표시하고 30초마다 WAV를 서버에 전송합니다.
4. 종료하면 마지막 30초 미만 구간까지 처리하고 마이크를 해제합니다. 전사가 완료되면 요약·교정·보관함 저장을 사용할 수 있습니다.
5. 실패한 전사는 순서를 유지한 채 멈춥니다. **전사 재시도**를 누르세요. 실패 중에도 녹음을 저장할 수 있습니다.

오디오 파일을 불러온 뒤 **파일 전사**로 처리할 수도 있습니다(24MB 이하). 재시도용 오디오와 현재 녹음은 메모리에 있으므로 페이지를 닫기 전에 다운로드하거나 보관함에 저장하세요. 보관함은 해당 브라우저/접속 주소의 IndexedDB에만 저장됩니다.

## 변경 사항

- Web Speech API 의존을 제거했습니다. AudioWorklet의 연속 PCM을 30초 단위로 나누고, 동일한 PCM으로 전체 WAV를 저장합니다. 불완전한 MediaRecorder 조각을 개별 파일처럼 업로드하지 않습니다.
- 준비된 마이크 스트림과 AudioContext를 재사용합니다. 시작 응답이 온 뒤에만 녹음 중으로 표시합니다.
- 랜덤 이퀄라이저 대신 같은 스트림의 AnalyserNode를 표시합니다.
- `/api/transcribe`: `gpt-4o-transcribe`에 오디오·언어·전문용어·이전 전사 문맥을 전달합니다.
- `/api/ai`: 서버에서 요약·교정을 수행합니다. 불완전한 AI 응답으로 원문을 덮어쓰지 않습니다.
- API 키는 `.env`에만 두고 정적 파일은 허용 목록만 제공합니다. 기존 `mmm_anthropic_api_key` 브라우저 저장값은 같은 출처에서 앱을 열면 삭제됩니다. 이전 GitHub Pages 주소 등 다른 출처의 저장값은 그 주소의 사이트 데이터에서 별도 삭제해야 합니다.
- 파일 크기·텍스트 길이·동시 요청·분당 요청을 제한하고 외부 출처 요청을 차단합니다.

## 배포

GitHub에 소스를 올리는 것과 서버 실행은 별개입니다. **GitHub Pages 단독으로는 `/api/transcribe`와 `/api/ai`를 실행할 수 없습니다.** Node 서버와 정적 페이지를 같은 출처로 서비스하세요.

외부에 공개할 때는 HTTPS 프록시 뒤에서 `HOST=0.0.0.0`, `APP_ORIGIN=https://실제주소`, `APP_USER`, 강한 `APP_PASSWORD`를 설정하세요. 접속 시 브라우저의 기본 인증 창이 나타납니다. 기본 설정은 로컬 접속만 허용합니다. 여러 사용자용 서비스에는 별도 사용자 계정·사용량 할당·영구 작업 저장이 필요합니다.

`.env`를 커밋하거나 브라우저에 키를 입력하지 마세요. 서버는 오디오를 요청 처리 중 메모리로 읽어 OpenAI로 전송하며 자체 파일 로그/오디오 파일 저장은 하지 않습니다.

## 검증

```sh
npm run check
npm test
```

자동 테스트는 WAV 헤더, 30초 경계/잔여 샘플, 스테레오 변환, 서버 업로드, 요약 응답, 입력 검증, 비밀 파일 접근 차단, 인증 및 공급자 오류 처리를 검사합니다. API 응답은 테스트 대역을 사용하며 비용을 발생시키지 않습니다.

선택적 Chrome 통합 테스트:

```sh
npm install --no-save --package-lock=false playwright
npm run test:browser
npm run test:pages
```

설치된 Chrome과 가상 마이크, 테스트 API를 사용합니다. `test:pages`는 `/mymeetingminutes/` 하위의 정적 사이트에서 언어 버튼·마이크 준비·녹음과 서버 부재 안내를 검증합니다. `BROWSER_EXECUTABLE`로 브라우저 경로를 지정할 수 있습니다. 실제 마이크·실제 API 품질을 측정하는 테스트는 아닙니다.

## 제한과 실제 환경 확인

- 전사는 약 30초 + 서버 처리 시간 후 나타납니다. 실시간 단어 미리보기는 제공하지 않습니다.
- 마이크 사전 준비가 권한/장치 초기화 지연을 앞당기지만, 첫 권한 승인 시간을 없앨 수는 없습니다.
- 정확도 향상 폭은 아직 실측하지 않았습니다. 조용한 한국어/영어/중국어, 전문용어, 먼 화자, 중첩 발화를 실제 API로 확인하세요. PCM 형식 자체가 인식률 향상을 보장하지는 않습니다.
- 모바일 Safari/Chrome에서 화면 잠금, 백그라운드 전환, 통화·블루투스 변경이 오디오를 중단할 수 있습니다. 화면을 켜 두고 실제 기기에서 확인하세요. 중단 시 오류를 표시하고 보존된 구간을 저장할 수 있습니다.
- 현재 메모리 기반 녹음은 세션당 1시간으로 제한합니다. 브라우저가 강제 종료되면 저장하지 않은 데이터는 사라집니다. 긴 회의는 나눠 저장하세요.
- 자동 화자 분리는 구현하지 않았습니다. 30초 경계에 걸친 단어는 이전 문맥으로 보완하지만 누락 가능성이 있으므로 중요한 내용은 녹음과 대조하세요.

공식 문서: [음성 전사](https://developers.openai.com/api/docs/guides/speech-to-text), [텍스트 생성](https://developers.openai.com/api/docs/guides/text).
